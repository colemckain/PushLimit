## Information Flow

```
User Onboarding Data
        ↓
┌───────────────────┐
│ WorkoutViewModel  │
├───────────────────┤
│ • userProfile     │
│ • assessment      │
│ • workoutPlan     │
└───────────────────┘
        ↓
┌───────────────────────────────────┐
│      Profile Screen Display       │
├───────────────────────────────────┤
│ IF hasCompletedOnboarding:        │
│   → Show Fitness Profile Section  │
│                                   │
│ IF currentWorkoutPlan exists:     │
│   → Show Workout Plan Section     │
│                                   │
│ IF assessment completed:          │
│   → Show Results + Retake         │
│ ELSE:                             │
│   → Show "Take Assessment"        │
└───────────────────────────────────┘
```

## Responsive Behavior

### **iPhone View:**
- Single column layout
- Full-width cards
- Stacked information
- Compact badges

### **iPad View:**
- Centered content (max 600px)
- Same layout, larger text
- More padding
- Better spacing

---

## Empty States

### **No Onboarding:**
```
Shows only:
- Profile Header
- Weekly Goals (editable)
- Instructions
- About
- Danger Zone
```

### **No Assessment:**
```
Shows:
- All sections
- "Take Fitness Assessment" button
- Plan based on activity level (not assessment)
```
